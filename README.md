# Tamweely Job Platform

منصة عربية متكاملة لإدارة التقديم على الوظائف داخل شركة Tamweely، مع نظام أدوار متعدد: المتقدم، أخصائي التوظيف، المشرف، والمدير.

## المميزات
- نظام تسجيل دخول آمن بالأدوار
- إدارة الوظائف والإعلانات
- التقديم مباشرة من رابط الإعلان
- متابعة حالة الطلبات
- لوحات تحكم لكل دور
- تصميم عربي بالكامل (RTL)
- تصميم متجاوب ومناسب للجوال والتابلت والديسكتوب

## التقنيات
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Auth: JWT + bcrypt
- Data: in-memory demo store (قابل للتبديل إلى MongoDB لاحقًا)

## التشغيل السريع

### 1) تثبيت الحزم
npm install

### 2) تشغيل المشروع
npm run dev

### 3) الوصول
- Frontend: http://localhost:5173
- Backend: http://localhost:4000
